Zero Trust MASQUE 注册

与 Usque 内核 config.json 配置文件数据结构一致，也可用于 MASQUE 转换器

第1步：注册 Cloudflare 账号并开通 Zero Trust

  1. 浏览器打开 Cloudflare 管理面板 https://dash.cloudflare.com 使用邮箱注册登录账号
  2. 点击导航栏中的 Zero Trust，首次选择计划-选免费套餐，Google 或 YouTube 搜索 “Zero Trust 注册教程” 可跳过绑卡
  3. 点击导航栏中的 Zero Trust - 设置，查看你的 团队名 填写到第2步输入框
打开链接 说明

第2步：登录 Zero Trust 并授权

  1. 输入 团队名 后点击下方按钮将打开 https://团队名.cloudflareaccess.com/warp 然后输入绑定的邮箱和验证码
  2. 登录成功后会跳转到一个 Success 成功提示页面，右键 → 查看页面源代码 (注意：成功页面中包含token值，有效时间为60秒，操作过慢会导致失效，需要刷新成功页面或view-source源代码页面，重新获取新token)
  3. Ctrl+A 全选把 完整的 HTML 源码 粘贴到下方第3步输入框

第3步：提取 token 并生成 MASQUE 配置

粘贴完整的HTML源码，会自动提取token，点击下方按钮将生成账号配置文件 config.json ，拖入MASQUE转换器



备用方案 - 使用 Windows 注册脚本

下载后解压，手动将 token 填入 bat 脚本运行即可生成.json
